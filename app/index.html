Kết nối cTrader Open API

Dữ liệu giá cTrader do server cung cấp sẵn cho mọi thành viên: bạn không cần (và không thể) nhập Client ID, Secret hay Access Token. Chart tự kết nối khi mở; bấm nút dưới đây nếu muốn kiểm tra lại.

Kết nối MT5 (Journal)

Mỗi tài khoản Discord có một EA key riêng. Dán API URL và EA key bên dưới vào EA trên MT5 (InpApiUrl, InpToken), Journal sẽ tự đồng bộ lệnh đã đóng của riêng bạn. Đừng chia sẻ EA key cho người khác.

Xoá tài khoản

Xoá vĩnh viễn tài khoản và toàn bộ dữ liệu của bạn (lệnh đã đồng bộ, số dư, EA key) trên server và trong trình duyệt này. Không thể khôi phục.

Tải xuống

SignalBridge Journal
Expert Advisor cho MetaTrader 5 · v3.00
Tải xuống

Link tải sẽ được cập nhật sớm.

Cài đặt nhanh

  1. Tải file EA về máy bằng nút phía trên.
  2. Mở MT5, chọn File > Open Data Folder > MQL5 > Experts rồi chép file vào đó. Nếu là file .mq5, mở bằng MetaEditor và bấm Compile (F7).
  3. Vào Tools > Options > Expert Advisors, bật Allow WebRequest và thêm API URL của Journal vào danh sách.
  4. Kéo EA vào biểu đồ bất kỳ, nhập InpApiUrl và InpToken (lấy ở mục Kết nối). Journal sẽ tự đồng bộ lệnh đã đóng.
